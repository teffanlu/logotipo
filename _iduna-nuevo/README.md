# IDUNA

Repositorio central del proyecto **IDUNA** (marca paraguas) y su primera categoría **IDUNA SKIN SYSTEM**: skincare y aparatología facial/corporal de uso doméstico y/o profesional, con **educación y curaduría honesta** como diferenciador.

> "El puente entre la cabina y tu casa."

Este repositorio es la **fuente de verdad** del proyecto. Todos los chats de trabajo (marca, compras, contenido, finanzas) leen y escriben aquí.

---

## Cómo usar este repositorio con varios chats

1. **Al empezar un chat:** pide que lea este repo (`teffanlu/IDUNA`) para tener todo el contexto.
2. **Al terminar o en hitos:** pide que guarde lo avanzado en la carpeta correspondiente.
3. **Regla de oro:** todo se trabaja en la rama `main`. Este README es el índice maestro.

| Chat | Escribe principalmente en |
|---|---|
| Marca y estrategia | `01-estrategia/`, `02-identidad-visual/` |
| Compras e importación | `04-compras/` |
| Contenido y redes | `03-negocio/` (y futura `05-contenido/`) |
| Finanzas / freelance | `03-negocio/` |

## Estructura

### `01-estrategia/`
- `identidad-de-marca.md` — Propósito, propuesta de valor, pilares, personalidad, tono, "la Mentora Honesta", el enemigo de marca.
- `arquitectura-de-marca.md` — IDUNA paraguas + SKIN SYSTEM + registro Clase 10 (SAPI).
- `segmentos-3-fases.md` — Desarrollo / Prevención / Madurez.

### `02-identidad-visual/`
- `variantes/` — Isotipo en versiones oficiales (charcoal, sobre crema, blanco/terracota, oro/charcoal, compacto, favicon).
- `sistema-de-color.md` — Paleta, roles y código de color por Fase.
- `tipografia.md` — Marcellus + recomendaciones.
- `guia-de-uso-logo.md` — Variantes, tamaños mínimos y reglas.

> El logo maestro, los mockups y el brand sheet se conservan en el repo de diseño aparte; aquí solo se versionan las variantes oficiales del isotipo.

### `03-negocio/`
- `plan-de-negocio.md` — Modelo, segmentos, finanzas, fases, riesgos.
- `analisis-competencia.md` — Competidores locales y posicionamiento.
- `calendario-lanzamiento.md` — Ruta de fechas hacia el lanzamiento Q4.
- `monetizacion.md` — Kits, recompra, afiliación con la cabina.

### `04-compras/`
- `sistema-compra-alibaba.md` — Búsqueda, evaluación y costeo de proveedores.
- `estado-proveedores.md` — Estado de gua sha, microcorriente, gel, etc.
