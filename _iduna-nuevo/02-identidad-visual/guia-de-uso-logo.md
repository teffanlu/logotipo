# IDUNA — Guía de Uso del Logo

## Concepto del isotipo
Símbolo abstracto de **trazo continuo (monolínea)**, orgánico y asimétrico. Lectura propia de la marca: "la sinergia entre la cabina y el hogar". NO es literal (no es una manzana). Pensado como **sello/estampa** en empaque.

## Archivos
- `variantes/isotipo-charcoal.svg` — isotipo solo, fondo transparente (archivo maestro del símbolo).
- `variantes/isotipo-charcoal-crema.svg` — principal (charcoal sobre crema).
- `variantes/isotipo-blanco-terracota.svg` — empaque a color.
- `variantes/isotipo-oro-charcoal.svg` — Línea Premium / referencia digital del foil.
- `variantes/isotipo-compacto-charcoal.svg` y `-crema.svg` — versión engrosada para tamaños pequeños.
- `variantes/favicon-32.svg` — favicon listo.

## Diagnóstico de legibilidad (medido del SVG)
- Parte más delgada del trazo = 3.4% del ancho del símbolo.
- A **16px** el trazo fino mide ~0.5px → se desvanece. **No usar el original en favicon.**
- A **48px en adelante** el original funciona perfecto.
- Para usos ≤32px usar la **versión compacta** (trazo engrosado).

## Reglas
- Tamaño mínimo del isotipo original: 48px. Para menos, usar versión compacta.
- Área de respeto ≈ altura de la "I" de IDUNA alrededor del logo.
- Evitar negro puro: usar Charcoal `#2D2D2D`.
- El terracota no se usa para texto pequeño de párrafo (solo titulares).
